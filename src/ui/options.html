Rule syntax

MyTeam matches the whole field, ignoring case and accents.
~myteam or *myteam* matches text anywhere in the field.
/team(red|blue)/i uses a regular expression.
'MyTeam' matches the whole field with exact case.

Regexes support groups, alternatives and repetitions through a bundled linear-time engine. Lookarounds, backreferences and repetition counts above 1,000 are unsupported. Regexes use Unicode code points; some Unicode edge cases differ from JavaScript’s native engine.

How hidden tags work

Twitch squeezes a few tags onto each card. When its response supplies the complete list, HexStream checks all of them.

Use a card’s ⬡ button to see available tags and coverage. “Visible tags only” means that view has not supplied the full list.
