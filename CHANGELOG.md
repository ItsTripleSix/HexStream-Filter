# Changelog

## 0.3.0 — first public release

- Firefox package signed by Mozilla for installation from GitHub; Chrome unpacked package included.
- Four blocking lists, four exception lists, pause, card inspection and recent hidden-item explanations.
- Filtering uses complete supplied custom tags, including tags absent from visible chips.
- Visible list tabs, import review, saved-rule export and protection against stale editor overwrites.
- 36 writing-system presets with separate Tags, Titles and Users choices. Existing character-range rules remain intact and are exposed as custom rows.
- Player/navigation/idle metadata retention prevents partial updates or cache expiry from erasing a connected card's known full tags.
- Compact main-card controls; no extra sidebar buttons. Sidebar filtering remains active.
- Bounded caches, indexed exact rules and avoidance of redundant full scans.
- Empty defaults; no bundled user preferences or automatic cloud sync.
- Matching Android/browser project links and detailed installation/filtering/privacy guides.

Earlier 0.1/0.2 builds were local test builds. See [VERIFICATION.md](VERIFICATION.md) for validation results, regression coverage and known limits.
